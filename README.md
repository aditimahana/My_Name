# Thank You & Say My Name 🐍

## 📖 Introduction

This repository contains two beginner Python exercises from Section 3 of *Teach Your Kids to Code*. The programs explore basic user interaction, variables, and repetition through simple text-based activities.

Both exercises demonstrate how Python can receive information from users, store it, and display personalised outputs.

## 📂 Programs

### 1. Thankyou.py

A simple interactive introduction program that asks the user for their name and age before introducing both the user and the program's creator.

**What it does:**
- Stores the programmer's name and age in variables.
- Asks the user to enter their name and age.
- Displays both sets of information.
- Prints a personalised thank-you message.

**Expected output:**

```text
What is your name? Alex
What is your age? 13
My name is Aditi, and I am 12 years old.
Your name is Alex, and you are 13 years old.
Thank you for running this program, Alex!
```

### 2. SayMyName.py

A repetition exercise that asks the user for their name and prints it 100 times, followed by the phrase "rules!".

**What it does:**
- Requests the user's name.
- Uses a `for` loop to repeat the output 100 times.
- Uses the `end` parameter in `print()` to control line breaks.

**Expected output:**

```text
What is your name? Alex
Alex rules!Alex rules!Alex rules!Alex rules!...
```

The message continues until the loop has completed 100 repetitions.

## 🛠️ What I Learned

- **Variables:** Storing information for later use.
- **User input:** Collecting information with `input()`.
- **Data types:** Working with strings and numerical input.
- **Output:** Displaying information using `print()`.
- **For loops:** Repeating instructions a specific number of times using `range()`.
- **Print parameters:** Using `end` to control how printed text is separated.

## 🚀 How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in your Python IDE.
4. Run either program:

```bash
python Thankyou.py
```

Or:

```bash
python SayMyName.py
```

Follow the prompts in the terminal.
